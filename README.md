# Join Aeiva

The iPhone-first waitlist experience for Aeiva — health data made clear, one
useful action at a time.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

The clarity-profile form is intentionally a frontend preview only. It does not
transmit or store responses until a waitlist destination and privacy flow are
connected.
